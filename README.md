## 📖 About

Auto Fish Helper detects the fishing rod float animation and automatically reels in and re-casts, maximising AFK fishing efficiency without hardware macros.

---

## ✨ Features
<a name="features"></a>

- **Auto Reel & Cast** — triggers on float animation, no hardware macro needed.
- **Treasure Detection** — pauses briefly to show caught items.
- **Inventory Full Stop** — stops when inventory is full.
- **Session Stats** — fish, treasure, and junk counts in HUD.
- **Toggle Key** — start and stop with one key.
- **Singleplayer & Multiplayer** — works where permitted.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
